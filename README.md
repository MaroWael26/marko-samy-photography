# Marko Samy Photography — Portfolio & Booking Platform

A sleek, dark-themed, highly dynamic portfolio landing page created for **Marko Samy Photography** (NJ Professional Photographer). This project highlights photography services (Weddings, Events, Portraits, Commercial), presents a filterable gallery with interactive Lightbox features, and provides a clear booking and pricing structure.

---

## 🌟 Key Features

- **Responsive & Modern UI:** Designed with a dark aesthetic (`#0a0a0a`), luxury gold accents (`#d4a843`), and full mobile/desktop responsiveness.
- **Filterable Gallery:** Seamless filtering across multiple categories (*All, Weddings, Portraits, Events, Commercial*).
- **Interactive Lightbox:** Full-screen high-resolution image viewer with keyboard navigation (`Esc`, `Arrow keys`) and caption overlays.
- **Package Selection Integration:** Dynamic package selection button that smooth-scrolls to the booking form while auto-filling the chosen service tier.
- **Scroll Animations & Effects:** Smooth glassmorphic header, custom scrollbar, reveal-on-scroll elements, and quick back-to-top functionality.

---

## 🛠️ Built With

- **HTML5:** Semantic markup.
- **Tailwind CSS (Play CDN):** Rapid layout utility classes and customized color themes.
- **Custom CSS (`style.css`):** Glassmorphism effects, Lightbox layout, and custom scroll behaviors.
- **JavaScript (`script.js`):** DOM manipulation for mobile navigation, filtering logic, and lightbox events.
- **Google Fonts:** *Playfair Display* (Headings) & *Inter* (Body text).
